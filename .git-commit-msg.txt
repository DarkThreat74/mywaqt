- updateEventInCache: when an event is moved to a different date, the
  old IndexedDB entry with the old _dateKey was never deleted, leaving
  a stale ghost event on the old date. Now checks for existing entry
  and deletes it if the _dateKey changed.
- syncGoalsToCache: goalType and targetDate fields were missing from
  the CachedGoal interface and the cache writer, so offline goals
  lost their type and due date. The Today tab filters by targetDate,
  so offline due-date filtering was broken.
- Month view: classes fetch was sequential (nested inside homework
  handler) instead of parallel — moved into the main Promise.all for
  faster page load.
