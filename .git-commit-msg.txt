fix: old share tokens show "no longer available" instead of redirecting

Old-format share links (32-char hex, 5-digit numeric) now show a clear
"This link is no longer available" message instead of redirecting to
the new URL format or showing a generic 404. When a user regenerates
their share code, the old link immediately stops working.

- Created ShareLinkExpired component with clear messaging and a link
  back to Waqt
- Legacy routes (/user/[token], /user/[name]/[token]) now render the
  expired message — no more redirects
- Main route (/[name]/[code]/public) shows the expired message when
  the token doesn't match anyone in the DB (regenerated or disabled)
  instead of a generic notFound()
