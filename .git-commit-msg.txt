fix: switch to @ffmpeg-installer/ffmpeg for full filter support on Vercel

ffmpeg-static ships a minimal Linux binary that was missing filter
options (likely leave_silence in silenceremove or loudnorm), causing
"Option not found" errors on all batch-processed talks.

Switched to @ffmpeg-installer/ffmpeg which provides full FFmpeg builds
with all filters enabled. Added to serverExternalPackages in
next.config.ts so Next.js doesn't try to bundle the platform-specific
sub-packages.

Removed the fallback chain logic — the full chain now runs directly:
  highpass → lowpass → silenceremove → loudnorm → Opus encode

Removed ffmpeg-static dependency.
