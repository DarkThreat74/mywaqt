fix: redesign media notification with proper metadata + draggable seek bar

Media Session API fixes:
- Artwork now uses the folder image (if available) at 512/256/192 sizes,
  falling back to app icons. Previously only showed the Waqt logo.
- "artist" field shows speaker, or folder name, or empty string —
  never the ugly "Unknown speaker" fallback.
- "album" field shows the folder name, or "Waqt Talks".
- setPositionState is now called on every timeupdate (browser-throttled
  to ~4Hz) so the notification seek bar tracks playback in real time
  and is draggable. Previously only updated near whole seconds.
- setPositionState guards against non-finite/zero duration and clamps
  position to 0..duration (fixes TypeError on live streams).
- seekto handler now uses fastSeek() when available for smooth scrubbing.
- seekbackward/seekforward now respect the seekOffset from the OS
  instead of hardcoding 15s/30s.
- PlayerTrack interface now carries folderName + folderImageUrl so the
  notification can show them.
- Closing the player clears Media Session metadata + position state so
  the notification doesn't linger with stale data.
