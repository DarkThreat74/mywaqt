Sadaqah card number:
- formatCardNumber was converting dollars to cents, so $1,000 showed
  as "0000 0000 0010 0000" which reads as $10,000. Now uses the
  dollar amount directly: $1,000 → "0000 0000 0000 1000".

Dhikr counter overflow:
- The tahlil phrase (la ilaha illallah wahdahu la sharika lah...) is
  the longest default dhikr and was overflowing the card, pushing the
  entire page down. Fixed by:
  - Adding break-words + max-w-full + min-w-0 to the text container
  - Reducing Arabic from text-3xl/leading-loose to text-2xl/leading-snug
  - Adding maxHeight to the card (min(75dvh, 560px)) with overflow-y-auto

Audio compression:
- Changed default MP3 bitrate from 160k to 64k
- Force mono output (talks are single-speaker, stereo wastes bytes)
- Lowered sample rate from 44100 to 22050 Hz (lowpass filter already
  removes content above 16kHz)
- Result: ~75% file size reduction. A 16.6MB talk becomes ~4MB.
  Speech quality is preserved — voice has no stereo content and
  little useful information above 16kHz.
