fix: offline playback, seek labels, talk ordering, admin play button

1. Offline talks playback — switching tracks didn't load
   Root cause: when track.id changed, the <audio> element's src
   updated but React state (duration, currentTime, isLoading) was
   not reset. The audio element also didn't reliably reload.
   Fix: added key={track.id} to force clean remount + useEffect
   to reset state and call audio.load() on track change.

   Also added .opus and .ogg to service worker audio interception
   (was only .mp3/.m4a/.aac — Opus files wouldn't be cached).

2. Seek button labels
   Added "15s" and "30s" text labels under the skip icons in both
   the mini player and full player.

3. Folder talk ordering
   Changed from orderBy(desc(addedAt)) to orderBy(asc(title)).
   Talks now sort alphabetically by title (1, 2, 3, 4...) instead
   of by upload date.

4. Admin play button
   Added AudioPlayerProvider + GlobalAudioPlayer to AdminShell.
   Each ready/published talk now has a play button that opens the
   same audio player as the customer-facing app, so admins can
   test audio playback directly.
