fix: use stop_silence instead of leave_silence for 1s pause buffer

Research via agent-reach + context7 found that stop_silence (added
FFmpeg 4.2, available in 6.1.1) does exactly what leave_silence did
but without the compatibility issues.

Filter chain now:
  highpass(80) → lowpass(16k) → silenceremove → loudnorm → Opus

silenceremove config:
  start_periods=1:start_duration=0.5:start_threshold=-50dB:start_silence=0.3
  stop_periods=-1:stop_duration=2:stop_threshold=-50dB:stop_silence=1

- Pauses > 2s: trimmed, 1s buffer kept (stop_silence=1)
- Leading silence: trimmed, 0.3s kept (start_silence=0.3)
- Pauses < 2s: preserved untouched
