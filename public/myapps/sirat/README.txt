SIRAT: how to put it online (2 minutes)

1. Go to app.netlify.com/drop
2. Drag this WHOLE FOLDER (the one containing index.html) onto the page.
   Do not drag the zip file and do not drag only index.html.
3. Netlify gives you a link that starts with https://. Open it in Chrome on your phone.
4. Menu (three dots) > Install app. Open it from your home screen after that.
5. Tap the locate button once and choose Allow.
6. Open the menu (top left of the app) > Offline streets > Main roads. Wi-Fi, keep the screen on.

Notes
- The site is set to stay out of search engines (robots.txt, noindex, headers). Anyone with the link can still open it, so don't post it.
- Location, install and offline only work on https links. A local file or an http link can't do them.
- Updating: replace the files on Netlify (Deploys > drag the folder again). Before you do, open sw.js and bump VERSION (for example fa-v5) if index.html changed.
- Downloaded roads live in the phone's browser storage. Clearing site data in Chrome deletes them.
- To start on a given tab, links like  yoursite.netlify.app/?tab=D  work (E eat, D do, M pray, S buy). Long-press the app icon for shortcuts.
